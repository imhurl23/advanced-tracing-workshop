# 👋 Welcome — Advanced Tracing Workshop

## While you get settled, install these tools:

### 1. Braintrust CLI (`bt`)

```bash
curl -fsSL https://bt.dev/cli/install.sh | bash
```

Verify install

```bash
bt --version
```

### 2. `uv` (Python package manager)

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Verify install

```bash
uv --version
```
